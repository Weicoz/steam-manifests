## 🎮 硬件运行建议与预估表现 (i5-9600K + RTX 2060 6G)

> 参考 doesitrun.com 跑分模型与虚幻引擎 5 实测调优。针对机器配置（Core i5-9600K 6核 / RTX 2060 6GB / 16GB RAM / 1080p 分辨率）：

- **推荐画质**：1080p 中画质 (Medium) + DLSS 质量模式 (Quality)
- **预估帧率**：**50 ~ 60 FPS**（平稳流畅）
- **画质微调指南**：
  - **动态分辨率/超分辨率**：开启 NVIDIA DLSS 并设为「质量 (Quality)」，在获得原生画质观感的同时提升约 30% 帧率。
  - **光线追踪**：**关闭**。RTX 2060 光追单元较少，开启会导致帧率大幅滑落至 30 FPS 以下。
  - **阴影与体积雾**：设为「中 (Medium)」，大幅降低 Shader 计算开销。
  - **显存保护**：纹理质量保持在「中 (Medium)」，避免 6GB 显存溢出导致偶发顿卡。
